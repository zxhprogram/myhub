Show HN: A new visual engine for modern web applications built on WebGL

person dev_null schedule Oct 24, 2023 • 10:42 AM

Hey everyone, for the past year our small team has been working on a new rendering approach for complex web interfaces. As web applications become more demanding, pushing large amounts of DOM nodes often leads to performance bottlenecks, especially in data-heavy tools or interactive canvases.

The Problem with Traditional DOM

We noticed that when building our internal analytics dashboards, attempting to render thousands of individual data points as HTML elements caused significant jank. Virtualization helps, but it doesn't solve the fundamental issue of the browser layout engine struggling with rapid, complex recalculations.

format_quote

"The goal wasn't to replace HTML, but to provide an escape hatch for the specific components that need 60fps rendering regardless of complexity."

Our Approach

We built a lightweight WebGL layer that sits seamlessly behind (or above) the standard DOM. It syncs with the React/Vue lifecycle, allowing developers to define complex visual elements using standard declarative syntax, which our compiler then translates into optimized shader calls.

  • Zero DOM overhead for data nodes.
  • Hardware acceleration enabled by default.
  • Seamless integration with existing UI frameworks.

We've open-sourced the core engine today and would love to get feedback from the community. You can check out the interactive demos on the repository.
