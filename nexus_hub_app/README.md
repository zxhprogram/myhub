# Nexus Hub App

A Flutter desktop/web application for Nexus Hub.

## Prerequisites

- Flutter SDK 3.44.0 or later
- Dart SDK 3.12.0 or later

## Run locally

```powershell
cd nexus_hub_app
flutter run -d windows
```

## Tests

```powershell
flutter test
```

## Architecture

- **Framework**: Flutter
- **State management**: Signals
- **Routing**: go_router
- **Networking**: Dio
- **Local persistence**: Hive
